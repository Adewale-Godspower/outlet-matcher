How the scoring works
  • Phone (cleaned): 0803…, +234 803… and 234803… are treated as the same number. If a sheet has two phone columns (e.g. existing: outlet phone + contact phone; surveyed: contact phone + owner's phone), map both — every number on both sides is checked against every other number, and any exact match counts. The second phone column is optional; sheets with one phone column work as before. A pair with an exact same phone number is marked AUTO_MATCH. The one exception: if two surveyed outlets claim the same existing outlet, only the stronger claim auto-matches — the other goes to Possible Duplicates. A near-identical outlet name is likewise always kept for REVIEW at minimum.
  • Names (fuzzy): spelling differences, word order, and filler words like Shop / Store / Ltd are ignored, so “Adebayo Stores” can match “Store Adebayo”. Titles (Alhaji, Mallam, Engr, Dr…) are ignored in owner names.
  • Name + location shortcuts: an almost-identical outlet name (≥ 90) within 100 m auto-matches even if owner/phone differ — and so does an almost-identical owner name (≥ 90) within 100 m when the outlet names also partly match (≥ 50). Outlet and owner names both ≥ 85 within the auto-match distance also auto-match. Recorded owners often differ between visits (owner vs attendant/contact), so they must not veto a strong name + location match.
  • Exact outlet + owner name: if both are almost identical (outlet ≥ 95, owner ≥ 90), the pair auto-matches regardless of distance — recorded coordinates are sometimes wrong or stale, and the note will flag any distance over 1 km so you can check those two records' coordinates.
  • Namesakes farther away: pairs that share a distinctive outlet/owner word are compared at any distance. A very similar outlet + owner name that is too far to auto-match goes to REVIEW (possible relocation or namesake) — never straight to Unmatched.
  • Distance: for pairs without a matching phone, candidates must normally be near each other. An exact phone match auto-matches regardless of distance — so spot-check phone-based auto-matches, because one owner/agent phone can serve several outlets.
  • One-to-one: if two surveyed outlets claim the same existing outlet, the higher score wins and the other is flagged as a possible duplicate survey.
  • Score: a weighted blend of outlet-name similarity, owner-name similarity, phone match and closeness (0–100).
